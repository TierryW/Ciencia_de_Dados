# Glossário

## Business Intelligence (BI):
Conjunto de estratégias e ferramentas focadas na análise de dados de negócios, permitindo que as empresas tomem decisões informadas com base em dados históricos e atuais.

## Data Analysis Expressios (DAX):
Linguagem de fórmulas usada no Power BI para criar cálculos personalizados em colunas e medidas, oferecendo funcionalidades avançadas de manipulação de dados.

## Dashboard:
Interface visual que exibe dados de forma consolidada e interativa, permitindo a análise rápida e eficiente de informações críticas para o negócio.

## KPIs (key Performance Indicators):
Indicadores-chave de desempenho que medem o sucesso de uma organização ou de uma atividade específica em alcançar objetivos estratégicos.

## Medidas Calculadas:
Cálculos personalizados criados no Power BI usando DAX, que permitem análises complexas e insights detalhados a partir dos dados.

## Microsoft Store:
Plataforma de distribuição digital da Microsoft, recomendada para a instalação do Power BI no Windows devido à facilidade de acesso e atualização.

## PowerBI:
Ferramenta de Business Intelligence da Microsoft que permite a criação de relatórios interativos e dashboards a partir de diversas fontes de dados.

## SQL:
Linguagem de consulta estruturada usada para gerenciar e manipular bancos de dados relacionais, frequentemente integrada ao Power BI para importação de dados.

## Visualização de Dados:
Processo de representar dados graficamente para facilitar a compreensão e a análise, essencial na criação de dashboards no Power BI.

## Visualização Interativa:
Elementos visuais que permitem a interação do usuário, como filtros e seleções, para explorar dados de diferentes perspectivas em um dashboard.
