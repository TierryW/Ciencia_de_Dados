# Glossário:

## Dashboard:
Uma interface visual que exibe dados e métricas importantes de forma consolidada, permitindo uma análise rápida e eficiente das informações apresentadas.

## Filtros:
Ferramentas utilizadas em dashboards para restringir ou modificar os dados exibidos, permitindo que os usuários visualizem informações específicas de interesse.

## Gráficos de Linhas:
Representações visuais que conectam uma série de pontos de dados com linhas, frequentemente usadas para mostrar tendências ao longo do tempo.

## Gráficos de Colunas:
Visualizações que utilizam barras verticais para representar dados quantitativos, facilitando a comparação entre diferentes categorias.

## KPIs (Key Performace Indicators):
Indicadores-chave de desempenho que medem a eficácia de uma organização em alcançar seus objetivos estratégicos.

## Looker Studio:
Uma plataforma online de visualização de dados que permite a criação de dashboards interativos, com integração facilitada com produtos Google.

## Power BI:
Uma ferramenta de análise de negócios da Microsoft que oferece recursos avançados de visualização e personalização de dados, exigindo instalação local.

## Visualização de Dados:
O processo de transformar dados complexos em representações visuais claras, facilitando a compreensão e a comunicação das informações.

## Visualização Personalizada:
A prática de ajustar elementos visuais de um dashboard, como cores, ícones e layout, para torná-lo esteticamente agradável e alinhado ao tema do negócio.
